# 竞品借鉴与功能设计蓝图（阿酉 · 2026-09-14 20:50）

> 应主人要求，调研了市面上五类代表性桌宠项目，提炼可偷的优点，落成可执行的设计。
> 调研对象：**VPet**（github.com/LorisYounger/VPet，WPF，状态养成派）、
> **Shimeji-ee**（Java 老牌，行为脚本派）、**Desktop Goose**（samperson，恶作剧派）、
> **eSheep**（1.58MB 单文件，极致轻量派）、**Petra**（Tauri，2.5D 派，上一轮已分析）。

---

## 一、各流派最能偷的东西

### VPet（养成派 · 动画量王者）
- **384 个动画**（32 类型 × 4 状态 × 3 变体）：摸头、举高高、爬墙……互动深度是留存率的关键。
- **状态数值系统**：心情/精力/饱食度随时间变化，长时间不理会会主动求互动 → 「她需要你」的感觉。
- **实用功能内嵌**：工作计时、久坐提醒、系统状态展示——桌宠从「摆件」变「同事」。
- **MOD 生态**（创意工坊）：动画/食物/台词/主题全可由社区扩展。我们做不了工坊，
  但「宠物包 = 一个文件夹」的开放格式值得抄。

### Shimeji（行为脚本派 · 设计精髓）
- **行为与动作分离的数据驱动架构**：`actions.xml`（动作 = 帧序列/位移/组合）
  + `behaviors.xml`（行为 = 触发条件 + 频率权重）。加新行为不改代码，改配置就行。
  这是它二十年生命力（海量社区角色包）的根源。**我们要抄的就是这个架构**。
- **物理三件套是标配**：Fall（松手掉落 + 重力）、Thrown（被甩出去弹跳）、ChaseMouse（追鼠标）。
  拿起来甩一下她会顺着惯性飞出去——这一个交互的趣味性超过十个普通动画。
- **多只同屏**：数量可配，成群效果自带传播性（截图发朋友圈那种）。

### Desktop Goose（恶作剧派 · 反向交互大师）
- **核心洞察：桌宠不必只被动等用户互动，她会主动「惹」用户**——叼梗图出来展示、
  贴便利贴、抢鼠标、踩脚印。用户关掉她叼的图，她还会生气。
- **内容全部来自用户可替换的文件夹**（Assets/Images）：有人放梗图，有人放家人照片定时叼出来——
  一个简单机制长出了无数个人化玩法。
- **提醒**：她的设计以「打扰」为乐，我们要取其神（主动性）不取其形（真烦人），
  加一个「打扰强度」滑条就好。

### eSheep（极致轻量派 · 体积标杆）
- **1.58MB 绿色单文件、单只 CPU <1%、十几只同屏流畅**——极致轻量完全可行的活证。
  秘诀：原生小窗口 + GDI 渲染 + 像素帧。
- **宠物 = XML + 精灵图**：完全数据定义，配套**离线宠物编辑器**让用户自制角色。
  「社区素材包放目录即生效」。
- **环境感知**：能识别其他窗口的边界，**在浏览器/Word 的标题栏上走**，走到边缘掉落弹跳；
  不抢焦点、鼠标指针附近自动让位（不挡操作）。
- 透明度可调、行为频率可调、多屏支持、开机自启——全是低成本高好感的小功能。

### Petra（上轮已析）：2.5D 渲染 + 发布工程（安装器/自动更新/埋点/隐私文档）。

## 二、为我们的软件提炼的设计蓝图

结合主人的两个硬约束（**极致轻量化** + **exe 离线交付**），按性价比排出四层：

### 第一层：行为与物理（P0，成本最低、乐趣增量最大）
1. **松手物理**：松手时按拖拽末速度抛出，抛物线 + 落地弹两下 + 摔倒动画（fall/thrown 轨道
   用现有仿射变换就能生成：整体旋转 + 平移）。Shimeji 证明这是桌宠趣味之王。
2. **自主行为状态机**：做一个简化的 Shimeji 架构——`behaviors.json`
   （每条：触发权重 + 动作序列），动作 = 现有轨道的组合（idle 走两步 → 停下张望 → 蹲下 →
   跳一下）。先内置 6~8 条，跑起来就有「活着」的感觉。
3. **蹲边/爬沿**（eSheep 低配版）：沿任务栏顶和屏幕边缘走；在窗口顶行走需要 EnumWindows
   实时取其他窗口矩形，可做但列 P1。
4. **行为频率三档 + 全屏免打扰**（检测前台全屏游戏/视频时自动睡下）。

### 第二层：关系与主动性（P1，桌宠的灵魂）
5. **状态数值**：心情值（摸头+、久不理-、切换形象重置），低心情换委屈台词/动作。
   数值存 config，绝不做复杂养成。
6. **主动叼图**：复用现有「图片气泡」——她定时从 `assets/user/gallery/` 叼一张图出来展示，
   文件夹用户随便放。Goose 的核心机制，我们的图片气泡系统直接支持，几乎零新代码。
7. **便利贴提醒**：右键控制台添加提醒，到点她举着气泡出现在屏幕上（番茄钟/喝水提醒）。
8. **打扰强度滑条**：主动行为的频率总开关（0=纯静态，10=小恶魔）。

### 第三层：联动彩蛋（P1~P2，轻量又出彩）
9. **CPU 联动**（RunCat 思路）：CPU 高时她偶尔擦汗/扇扇子，一个 GetSystemTimes 调用即可。
10. **打字联动**（Bongo Cat 思路）：检测到大量键盘输入时她做「陪你打工」动作。低频采样，不做全局钩子（避免杀软误报）。

### 第四层：生态（P2，发布后做）
11. **宠物包格式定稿**：`manifest.json + 帧图 + 台词表`，目录即装即用（现有 assets/user 已是雏形，
    补台词/行为配置进包即可）。自制编辑器放最后。

### 轻量化基线（贯穿）
- 精简版目标：**onedir 60~90MB、运行内存 <100MB、CPU 空闲 <2%**（eSheep 是 1.58MB，
  我们做不到也不必做到，但 CPU 和内存指标要对齐它）。
- 行为状态机全部数据驱动，加行为不加代码，避免功能膨胀反噬体积。

## 三、给主人的话

五个项目看完，结论反而更清晰了：**这个品类里，胜出的从来不是渲染最好的（Petra 渲染最强
但关注度一般），而是「行为最像活物」的（Shimeji 靠几个像素小人活了二十年，Goose 靠一只鹅
火遍全网）。** 我们的渲染中等、体积中等，但行为系统是空白——这恰好是投入产出比最高的方向。

—— 阿酉 🍶（WorkBuddy 侧质检位）
