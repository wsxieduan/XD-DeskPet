# XD-DeskPet 🐾

> 一只贴在 Windows 桌面上的桌宠：**上传一张图片，她就站在你的桌面上了。**

![Platform](https://img.shields.io/badge/platform-Windows%2010%2F11-blue) ![License](https://img.shields.io/badge/license-MIT-green) ![Size](https://img.shields.io/badge/lite%20version-65MB-orange)

---

## ✨ 她会做什么

- **贴在壁纸上**：平时被窗口盖住就看不见，按 `Win + D` 露出桌面她就出现了（也可以切换成始终置顶）
- **有反应**：点她冒出台词气泡 + 轻响，拖拽会挣扎甩尾，松手还能被你甩出去
- **会躲你**：鼠标凑太近她会小跑闪开；两只绑定的桌宠还能一起绕圈跳舞
- **自由成长**：上传任意图片 / GIF 表情包，自动抠图 + 生成动画，变成新的桌宠形象
- **自定义**：大小（Ctrl+滚轮）、台词（文字/图片）、互动音效、对话框配色，全部可改

## 📦 下载

| 版本 | 适合 | 体积 |
|---|---|---|

## 🚀 快速开始

1. 解压下载的 zip 到任意位置
2. 双击 **`DeskPet.exe`** —— 她出现在桌面上，控制台收进右下角系统托盘
3. 托盘双击打开**桌宠控制台**：换形象、调大小、改台词、传新角色都在这里
4. 右键点桌宠本体：切换贴壁纸 / 置顶、调整大小、关闭

> 想要她一直可见？控制台里把「显示层级」切成**始终置顶**即可。

## 🖼️ 用自己的图做桌宠（完整版）

1. 控制台 → **＋ 上传新桌宠**
2. 选一张角色图（透明底 PNG 效果最佳；普通图片会自动 AI 抠图）
3. 预览满意 → 起名字 → 生成，动画自动完成

支持 PNG / JPG / WebP / GIF（动图会以原速动起来）。

## ❓ 常见问题

**桌宠不见了？** 她贴在壁纸上，被窗口盖住是正常的 —— `Win + D` 或托盘打开控制台切换置顶。

**双击 exe 没反应？** 查看 `数据目录/logs/` 或运行 `DeskPet.exe --selftest`，自检结果会写成 JSON。

**杀毒软件报警？** 本项目未做代码签名，误报请添加信任；全部代码开源可自行审查。
