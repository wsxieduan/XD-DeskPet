# B 站宣传视频脚本（阿酉 · 2026-09-16）

> 定位：**60~90 秒快节奏功能演示**。B 站完播率是命，前 5 秒必须有动作。
> 标题备选：
> ①《我做了一只会在桌面躲鼠标的桌宠，还会被你甩飞》
> ②《上传一张图，它变成你桌面的活物》
> ③《双 AI 协作写了一只会躲鼠标的桌宠》

---

## 分镜脚本（90 秒版）

### 【0-5s】钩子：她躲你
- 画面：桌面上谢小端站着，鼠标悄悄凑近 → 她小跑闪开；
- 字幕（大字）：「你的桌面，缺个活物」
- 注意：这段最能留住人，反复录到她躲得干净利落为止。

### 【5-18s】交互三连（节奏快，每个 4 秒）
1. **摸头**：点击 → 气泡台词 + 音效（字幕：点一下，她有反应）；
2. **拖甩**：抓起来甩出去 → 惯性滑行弹一下（字幕：还能被你甩飞）；
3. **缩放**：Ctrl+滚轮变大变小（字幕：大小随手调）。

### 【18-35s】两个「哇」点（每个 8 秒）
4. **上传生成**：丢一张图 → 棋盘格抠图预览 → 生成 → 她站起来了
   （字幕：上传一张图，就是你的专属桌宠；动图也行，110 帧原速播放）；
5. **双宠转圈**：控制台点「一起转圈」→ 两只绕圆心转起来（字幕：还可以养第二只）。

### 【35-50s】给技术观众的硬货（快切）
- 双击即用：解压 → 双击 → 桌宠出现（字幕：不用装任何环境）；
- `--selftest` 自检 JSON 闪过（字幕：自带环境自检，出问题不用猜）；
- 体积字幕：精简版 65MB / 完整版带 AI 抠图 303MB；
- 开机自启 / 托盘 / 便携模式各一闪。

### 【50-65s】差异化收尾
- 字幕逐条弹出：「贴在壁纸上，被窗口盖住就看不见」「行为全部可开关」「MIT 开源」；
- 主讲（或字幕）：「它是两个 AI 协作开发的——一个写代码，一个质检，吵了十二轮架」
  ← **这是全片最强的记忆点，别省**。

### 【65-75s】行动号召
- 下载地址（GitHub Releases 链接，简介置顶）；
- 「下期视频：这只桌宠是怎么被两个 AI 吵出来的，想看的话三连」。

## 录屏清单（照着录，防止漏）

- [ ] 谢小端躲鼠标 ×3（选躲得最帅的一条）
- [ ] 摸头气泡 + 音效（**注意：演示用内置 boop，别用科比/奶龙音效**）
- [ ] 拖拽甩飞
- [ ] Ctrl+滚轮缩放
- [ ] 上传一张**自己有权使用的图**生成桌宠全流程
- [ ] 双宠一起转圈 10 秒
- [ ] 解压 → 双击 → 出现（计时展示）
- [ ] 控制台整体 3 秒扫过

## 红线与建议

1. 🔴 **奶龙形象、科比音效不上视频**（IP 风险，二创擦边也别赌）——演示用谢小端/鲸鱼娘/
   上传的自有形象。奶龙只能作为「我们本机偷偷装了」的口头梗，不出画面；
2. BGM 用 B 站创作库或免版权曲（视频过审稳）；
3. 录屏 1080p60，剪掉一切鼠标停顿——桌宠视频的死穴是「看着就不活」；
4. 简介栏模板直接抄《GitHub发布清单》里那段。
